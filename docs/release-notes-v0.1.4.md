# v0.1.4 安装卡死修复 + 步骤可视化

## 修复

- **「思灵无法关闭」安装卡死**：开着旧版安装新版时，旧版卸载器检测到运行中的
  思灵进程（close-to-tray 拦截关闭、进程不退），弹「思灵无法关闭」并卡死在
  卸载步（进度约 50%）。安装器现在于安装前强杀运行中的思灵（仅 `思灵.exe`，
  不误伤其他 Electron 应用）。

## 新增

- **安装器步骤清单**：NSIS 安装详情区强制展开，按 ① 关闭运行中的思灵 →
  ② 卸载旧版 → ③ 复制程序文件 → ④ 注册与快捷方式 → ⑤ 完成 打印进度流水，
  卡住时最后一行即卡点。
- **启动/部署步骤清单**：splash 启动页展示主流程清单（环境检查 → 部署运行环境
  → 启动内核 → 加载界面 → 就绪），部署阶段细分为 解压 → 校验 → 替换 → 收尾；
  完成项打勾、当前项高亮，出问题时高亮行即卡点，反馈一句话即可定位。

## 更新说明

- v0.1.3 用户覆盖安装本版即可；首启版本检测正常触发重部署。
