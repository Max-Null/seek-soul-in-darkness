# v0.1.4 安装卡死修复 + 步骤可视化 + 三项优化

## 修复

- **「思灵无法关闭」安装卡死**：开着旧版安装新版时，模板自带的杀进程流程对
  close-to-tray 无效（优雅关闭被拦截成隐藏到托盘，循环强杀后仍弹
  appCannotBeClosed 卡死在卸载步）。安装器现在于向导启动即强杀运行中的思灵
  （仅 `思灵.exe`，不误伤其他 Electron 应用）。

## 新增

- **安装步骤清单**：安装详情区自动展开，显示 5 步清单（① 关闭运行中的思灵 →
  ② 卸载旧版 → ③ 复制程序文件 → ④ 注册与快捷方式 → ⑤ 完成）；进度条上方的
  状态文字同步显示当前步骤，尾部分步停留（各 1.2s）保证可见。卡住时最后
  一行即卡点。
- **首启部署步骤清单**：splash 启动页展示主流程清单（环境检查 → 部署运行环境
  → 启动内核 → 加载界面 → 就绪），部署阶段细分为 解压 → 校验 → 替换 → 收尾；
  完成项打勾、当前项高亮。
- **dsh-plugin-center 预制插件**：插件中心随安装包开箱即用，关于页插件清单
  可见。
- **logo 圆角**：应用图标与品牌 logo 圆角化（四角透明），exe/快捷方式图标
  随安装包生效。
- **伪 3D 载入动画**：splash 启动页的 Si 原子移植 fractal 的 Canvas 数学投影
  3D 渲染——三条倾斜轨道公转、近大远小、z 分层遮挡、瞳孔环顾、辉光呼吸。

## 更新说明

- v0.1.3 用户覆盖安装本版即可；首启版本检测正常触发重部署。
