## 十、品牌规范速查

| 项目 | 规范 |
|---|---|
| 中文名字体 | 思源黑体 / 苹方，字重 Bold，字间距 +50 |
| 英文字体 | Inter / San Francisco，字重 Light |
| 主色 | 深蓝黑（#0A0E14）为主，微光青（#4FC3F7）为辅 |
| Logo 展示 | 深色背景上放 Si 原子结构 + 瞳孔（发光效果） |
| 品牌色应用 | 瞳孔发光色 = #4FC3F7，用于按钮悬停 / 焦点 / 加载动效 |
| 氛围音效（如有） | 低频鲸歌 + 深海环境音（深沉、静谧） |
| 交互动效 | 加载时气泡缓缓上浮；瞳孔在鼠标悬停时有微弱收缩 / 凝视动画 |

> 备注：深海巨鲸意象致敬 DeepSeek 的鲸鱼 logo；保持克制，避免在视觉上被误认为 DeepSeek 官方产品。
