# v0.1.0 思灵（SSiD）初版

于黑暗中，探寻灵魂。

## 自研壳（不改 DSH 一行，跟随上游持续更新）

- 无边框自绘标题栏：Si 瞳孔品牌、窗口控制、拖拽/双击最大化、**主题实时跟随**（token + body 双路，兼容皮肤插件）
- 托盘（关闭最小化、首次提示）、品牌启动页、单实例锁
- Electron 单进程直嵌 DSH 内核；打包形态经 esbuild 预编译 bundle（不依赖 tsx 运行时）

## 侧栏生态

- dsh-better-sidebar：文件树/编辑器/终端/Git/子代理拓扑/内嵌浏览器/底部面板
- 扩展插件：Office 三件套内联预览、视频预览、Excel 编辑面板、划选提问

## SSiD 面板（@max-null/dsh-ssid-panels）

- 记忆（三态过滤/搜索/人工确认）、状态（Guardian 断言/审查队列）、习惯（自学习候选两级闸门）、余额（DeepSeek + Kimi 实时）

## 预制插件全家桶

中文思考 · 跨会话明文记忆（BM25）· Guardian 状态引擎 · 自学习习惯引擎 · 皮肤（预设调色板/壁纸/字号）

## 设置页「关于 SSiD」

版本 / 检查更新 / 更新日志 / 预制插件清单（版本+简介，实时读取）

## 安装器

- NSIS 向导：安装目录选择、桌面/开始菜单快捷方式
- 首次启动自动铺设 profile 并安装预制插件（约 430MB，需系统 pnpm）
- 运行前置：`DSH_CHECKOUT` 指向 DeepSeek Harness 仓库（v0.1.0 已知约束）
