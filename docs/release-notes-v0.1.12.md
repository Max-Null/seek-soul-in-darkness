# v0.1.12 发布说明（2026-08-25）

> v0.1.10 / v0.1.11 为本地构建验证版（未外发），v0.1.12 为包含期间全部修复与功能的正式发布。

## 内置升级

- **dsh-better-sidebar 0.16.0**：侧边栏升级至最新（0.15.2 的版本范围约束不会自动跨 minor，本次显式对齐）
- **dsh-plugin-center 0.2.12**：更新检测支持「纯前端热更新」识别（无需重启即生效）、安装直装/待重启/指令三段式完善
- **dsh-capture 0.2.0（截图引用大幅增强）**：
  - 标注升级：矩形/椭圆/**箭头**/**文字** + 8 色板（红橙黄绿青紫品红白，每条标注独立着色）
  - **双投递**：有标注时投递「原图 + 编辑图」两张（原图不遮挡原始内容，帮助理解方对照上下文）；无标注只投原图
  - **原图预览编辑闭环**：任何已插入图片打开「原图预览」即可 ✎ 直接编辑（同一套标注工具），完成后编辑图自动投递、预览窗口一并关闭
  - 修复：线条图标（箭头/撤销）不可见、文字输入回车误触发完成、窄图工具条文字挤压换行
- **dsh-web-preview-panel 0.2.4**：对话右上角 ▶ 打开侧边网页预览面板——本地文件/项目运行预览、🖉 元素标记（outerHTML 快照 + 批注）一键发送对话、链接点击接管、文件拖入工作区
- **Playwright MCP 预制**：安装版自动挂载 Playwright MCP（内置 node 运行时 + profile 内 cli 自动定位），浏览器二进制首次使用需 `playwright install chromium`
- 全家桶（chat-rail / memory / guardian / habit / node-appearance / skill-mcp-center / draft-polish / chinese-thinking / header-unify / ssid-panels / ssid-zh-ui）同步对齐

## 调整

- **open-sea-skin（海洋皮肤）默认不开启**：首装不渲染海洋背景（WebGPU/WebGL2 重负载），设置面板按钮常驻，需要时一键启用；已启用用户保持其设置
- 截图「无编辑只产出一张」：未画任何标注时不再重复投递编辑图

## 修复

- **插件中心更新假成功**：特定场景下 pnpm 静默不落盘（exit 0、版本未变）会被误报为「已热生效」——现核对安装版本，未生效报真实错误并附手动执行命令（v0.2.12）
- dsh-capture 预览编辑：图标缺失、完成后面板未关闭、工具条挤压换行（同版本修复）
- vendor 预制版本对齐（dsh-capture 包内版本号与构建一致，安装版首启不再误报「可更新」）

## 更新说明

- 老用户安装 v0.1.12：启动时版本指纹不一致 → 自动重部署运行环境（约 30 秒，可跳过；重部署后 profile 与本版预置一致）
- 全新安装：首启自动部署（进度条），全程无需 Node.js / pnpm
- Playwright MCP 首次使用前需安装浏览器二进制：在思灵内终端执行 `playwright install chromium`（或由 agent 代为安装）
