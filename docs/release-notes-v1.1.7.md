# v1.1.7 思灵（SSiD）

> 状态：**待发布**（2026-10-08）。新增预制插件「剧本杀」；随包插件跟到各自最新。

## 这一版改了什么

### 一、新增预制插件：剧本杀（`@max-null/dsh-jubensha` 0.1.0）

装完即用，不需要额外配置。它把剧本杀的真实门槛拆掉了 —— 那个门槛**不是钱，是人**：四到六个玩家加一个 DM，凑齐一次比票价难得多。这里 AI 坐 DM 位（它本来就该全知），AI 填满其余的椅子（各自只知道自己的角色本），**你一个人就能开局**。

会话视图因此多出一个标签：与「对话 / 轨迹 / 上下文」并列的**「团队」**房间。左栏是这一局的人（座位、人物关系、时间线），中栏是剧本正文与当前阶段那一页，右栏是桌上说了什么；便签可以留在任意位置，跟着标签走、按会话存。人物关系在窄栏里是列表，点开弹窗才是连线图（死者在正中、角色在四角）。

设置页在**侧栏「插件」→ `@max-null/dsh-jubensha` 卡片**里：演员池（名字、怎么玩、跨局印象）、本子上哪儿找、加目录都在那一页。

顺带两条不算界面的变化：阶段与线索有机器可读的记录（复盘直接读事件日志，不靠 DM 回忆）；玩家 agent 的工具面在创建时被收窄 —— 它们能说话，但读不到本子文件。

### 二、随包插件跟进最新

| 插件 | 从 | 到 |
|---|---|---|
| `@astudioplus/codegraph-mcp` | 0.20.1 | 0.21.0 |
| `dsh-wechat` | 0.9.10 | 0.9.11 |

- **codegraph-mcp 0.21.0** —— 包自身只改了引擎下载逻辑（`bin/fetch-engine.js`）与版本元数据，主入口 `bin/codegraph-mcp.js` **逐字节未变**，所以工具面与调用方式照旧；随之更新的是随包的索引引擎（`codegraph-server-*`，约 105 MB + onnxruntime 11 MB）。引擎与包版本必须同批，本版两者同为 0.21.0。
- **dsh-wechat 0.9.11** —— 相邻 patch，改动落在微信桥（`dist/bridge`）与会话操作（`dist/dsh/ops`）。

其余 24 条 npm 形态的预制依赖核对后**已是最新**，未做改动。

### 三、`dsh-better-sidebar`：补一个尚未发到 npm 的修复

侧边栏这份仍是我们 fork 的产物（上游 PR 已合并、但**尚未发版**，npm `latest` 仍是 0.24.1），所以它一直靠 vendor 形态随包。本版把 fork 上一个**此前没同步进来**的修复带上：

**并发同名上传的 rename 争用** —— Windows 上多个上传同时把临时文件 rename 到同一个目标时，同一瞬间的 rename 互斥、输的那一个会被**拒绝**（`EPERM`/`EACCES`/`EBUSY`），而它只是争用、不是判决。原来的实现一次不成就把失败报给用户。现在改成有界重试（上限 10 次，实测 8 方并发下最坏一次吸收 8 次拒绝），其他 errno（`ENOENT`/`EXDEV`/`EROFS`…）仍是真答案，首次抛出即传播 —— 重试有界，所以真正被占住的目标仍会失败而不是挂住。

## 升级说明

- **覆盖安装即可**，会话、工作区、插件配置与跨会话记忆都保留。
- **剧本杀是新增的**：装完就能用，不入配置文件、不动既有数据。想开一局时对模型说一声即可；它自己带本子（七个已实测的本子随包），也可以指向你自己的本子目录。
- **本版没有改动壳代码**，只有随包插件集的变化 —— 升级后行为上的差异都来自上表的插件。
- **不买证书的既定取舍**：安装包未签名，Windows 的「无法验证发布者」提示点「运行」即可。
