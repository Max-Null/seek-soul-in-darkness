# v0.4.0 思灵（SSiD）

> 状态：**已发布**（2026-09-21）。按 `git log v0.3.3..HEAD` 分组（29 个提交）。
> 归档指纹 `0.4.0-0.1.5-rc.2-462c5c70` · Windows 三层内核哈希 `376de942a96d7c77`。
> 本版是**功能版**：核心围绕「跑长任务时离开电脑」这一个场景——执行期间阻止系统睡眠与息屏，
> 并给窗口盖一层毛玻璃遮罩（底下看得见有动静、读不出内容），解除要长按 2 秒、可选口令。
> 另新增预制插件 `dsh-allostasis`（应变），并让门禁终于能管住「模板改了、运行时没跟上」这类漂移。

## 新增

- **执行期间保持系统不唤醒**：会话或目标正在跑的时候阻止系统睡眠与息屏，一轮结束后再保持
  一段时间（默认 60 秒）以覆盖多轮之间的空隙，跑完自动释放。判据落在「**任何** `turn/end`
  都释放」，而不是「只有正常完成才释放」——出错、用户中断、超预算都从这条路走；照抄完成通知
  的判定会让出错后**永不释放**，屏幕再也关不掉。状态机抽在 `shell/lib/keep-awake.mjs`，
  副作用（起停/读配置/计时器）全部注入，配 9 条单测覆盖并发轮次、尾巴期内再起一轮等序列。
- **执行中遮罩（毛玻璃）**：托盘菜单或 `Control+Alt+M` 给窗口盖一层全屏毛玻璃——**底下看得见
  有动静、但读不出内容**，离开电脑去吃饭时挂着正合适。文案可自定义（默认「程序执行中，勿动」），
  浓度与模糊半径可调（默认 0.12 / 10px）。
  实现上绕了一圈：独立窗口做不出这个效果（Windows acrylic 的不透明度与半径被 DWM 定死，
  只剩一片均匀浅灰；透明窗口 + 页面 `backdrop-filter` 又取不到窗口背后的 backdrop），
  最后改为**把遮罩注入 DSH 页面内部**——同页面内的 backdrop-filter 半径完全可控。
- **遮罩解除口令**（可选）：留空则不设防（长按 2 秒直接解除）；设了口令之后，**托盘项、全局
  快捷键、长按按钮三个入口都要求先输入口令**——只给按钮加是没用的，托盘一点就开了。
- **设置入口**：保持唤醒开关、结束后的保持时长、遮罩文案、遮罩快捷键、遮罩观感、解除口令
  六项，都在「设置 → 关于 SSiD → 通知设置」。
- **内核日志随 `SSID_LOG_FILE` 隔离**，ready 后落 `ssid-runtime.json`。
- **`profile` 名参数化**（`SSID_PROFILE_NAME`）：并行开隔离实例时会话根随 profile 名走
  （`sessions-<profile>`）——两个宿主共写同一份 JSONL 会反复造成 seq gap。

## 内置升级

- **`dsh-sidebar-qa` 0.5.0 → 1.0.0**：改用 DSH 原生右侧栏，去掉 `dsh-better-sidebar` 依赖；
  拿不到原生侧栏时降级而不再拖垮启动。
- **`dsh-context` 0.53.3 → 0.54.0**、**`@playwright/mcp` 0.0.81 → 0.0.82**、
  **`dsh-session-manager` 0.4.11 → 0.5.1**；`dsh-node-appearance` 0.5.0、`dsh-memory` 0.11.0、
  `dsh-guardian` 0.2.1 的 pin 一并对齐到运行时。

  拆开后各带独立 `--user-data-dir`，两个可同时开浏览器。附带 CLI 缺失护栏。

## 工程与门禁

- **`check-profile-sync` 补两条判定**：判定 3 补上「方向」——B 落后于 A 是可预期的稳态，**B 超前
  于 A** 才是坑（下次部署会被覆盖，必须补进模板），两句话要求的动作恰好相反；新增判定 6 管
  `cordis.patch.yml` 漂移——**dev 裸跑不部署**，模板改了 patch 不会自动流到运行时，此前只能靠人
  发现（本版实测：Playwright 双条目在模板里躺了一天，运行时仍是旧的一条且缺护栏）。
- **`ssid-cdp` 补 `type` 命令**（往输入框打文本），补齐驱动脚本的能力。
- **README 补「截图」段**：执行中遮罩的效果、口令输入态、设置页三张。
- 手册补坑 #37–#40（差异方向即判据、共用信号≠共用判据、跨窗口做不了毛玻璃、patch 漂移）。

## 修复

- **悬浮球「会话管理」点了没反应**：两层原因叠加——① 隐藏原按钮时用 `display:none`，连带把
  portal 进那个容器的面板一起埋了（面板 rect 变 0×0）；② 面板开合判据用的 `offsetParent` 对
  `position:fixed` 浮层恒为 `null`，于是每次点击都再点一次原按钮，而那个按钮是 toggle，
  开→关→开→关，看起来就是「没反应」。
- **splash 从 DSH 底下渗透到输入框**：`addBrowserView` 前给主视图设不透明底色，否则启动画面会
  从半透明的 DSH 底下渗上来，在输入框卡片的 `backdrop-filter` 上表现为一块边界笔直的浅色矩形。
- **`backup-storages` 没备份工作区记忆**：原实现只扫 `~/.dsh`，而记忆主体在
  `<工作区>/.dsh/storages/` —— 实测被备份的是 55 KB / 18 条，没被备份的是 212 KB / 108 条，
  主体反而裸奔。
- **遮罩文字改用光晕**：白字加一圈黑晕，亮背景暗背景都读得清（原先的深色衬底会挡住中央内容）。

## 更新说明

- 老用户升级：启动时自动检测版本不一致 → 自动重部署运行环境（约 30 秒，可取消），旧版无损。
- **遮罩入口**：托盘菜单「显示执行中遮罩」，或全局快捷键 `Control+Alt+M`
  （该键在本机实测空闲；被占用时可在设置里改）。
- 遮罩**默认不设口令**；要设就填「解除口令」。
- 这个遮罩**不是安全边界**：口令明文存在 `~/.ssid/notify.json`，忘了就改文件删掉它。
