# v1.0.0 思灵（SSiD）

> 状态：**待发布**。按 `ssid-desktop/SSID-CHANGES.md` 的改动 1–32 与壳提交历史分组。
> 本版是**换代版**：桌面壳从自建壳（≤0.4.0）换成**官方 DSH 桌面端底座的 fork**，
> 随包内核从 **0.1.5-rc.2 升到 0.1.7-rc.2**。产品版本自此与内核版本**分两条线**：
> 思灵自己一个号（本版 `1.0.0`），内核一个号（`0.1.7-rc.2`）。

## 这一版换了什么

- **底座换代**：不再自研窗口框架，改为在官方桌面端基座上改造——内核随包进 `app.asar` 的
  `dsh/`，Host 由官方的 `dsh-desktop-host` 担当，窗口能力（无边框自绘标题栏、托盘、
  窗口控件）沿用官方实现。**换来的好处**：DSH 升级时跟上游走，而不是每次重写窗口层。
- **内核 0.1.5-rc.2 → 0.1.7-rc.2**：随包内核整体前进两个版本线。会话格式随之升到
  **v4**（迁移器链 `v0→v1→v2→v3→v4` 会读旧会话，见「更新说明」）。
- **产品版本独立**：以前产品版本挂在壳的 `package.json` 上、被迫等于内核版本；现在
  安装包名、`latest.yml`、发版记录、GitHub tag 都跟**思灵自己的号**走。

## 保留的能力

自建壳时代做出来的东西，在 fork 形态下**逐项接线回来**，不是重写：

- **执行期间保持唤醒**（keep-awake）：会话或目标在跑时阻止睡眠与息屏，跑完自动释放。
- **截图**（dsh-capture）：含标注编辑、双投递（原图 + 编辑图）、独立热键配置。
- **执行中遮罩**：托盘或 `Control+Alt+M` 盖一层毛玻璃，解除需长按 2 秒、可选口令。
- **原生通知**、**托盘菜单**（含对照模式、重启内核、纯净模式）。
- **CodeGraph 索引目录适配**、**预制 MCP 的配置条目与运行时 env 成对落地**。
- **自绘标题栏**：隐藏官方标题栏，自绘 40px caption——品牌区、统一按钮组、窗口控件。

## 新增与调整

- **品牌**：产品名「思灵」、appId `com.maxnull.ssid`、图标与托盘位图、窗口标题。
- **随包插件集（A′ 形态）**：出厂插件**实体随包一份**（32 bundles / 616 packages），
  首启由壳把 profile 里的依赖写成指向插件集的目录链接——新装机开箱即有全套插件。
- **打包链打通**：Windows 未签名 dir 版与 NSIS 安装包可用（19 阶段流水线，自带打包后冒烟）。
- **标题栏让位改为动态测量**：量 caption 区页面元素的右边界，不再写死 48px；
  并**接管**官方在 caption 区的两个按钮（侧边栏开关、新建会话），功能收进自绘工具栏。
- **profile 名可配**（`SSID_PROFILE_NAME`）：并行开隔离实例时会话根随 profile 名走。

## 修复

- **标题栏「应用 / 编辑」菜单不该出现**：官方 caption 菜单会与品牌区抢标题栏左上角，
  且切换会话时闪现。现在**默认隐藏**（菜单仍挂载在 DOM 里），**对照模式下才放出来**——
  这样「看 DSH 原样」依旧完整。同时收紧让位口径：只认**整块**落在 caption 带内、
  且本身窄（≤200px）的页面元素（此前擦到这条带的 composer 控件、右侧面板按钮都会被算成
  占位，实测能把让位撑到整窗宽、品牌区被整个推出视口）。
- **初始 profile 的 patch 合并误判**、**旧 profile 自动换代**。
- **标题栏读取 DSH 内核版本**，而不是产品版本（换底座后两者不再相等）。
- **会话存储根环境变量注入**，隔离根恢复生效。

## 更新说明

- **老用户升级是换壳，不是打补丁**：安装 1.0.0 后首启会按新形态初始化（内核随包、
  profile 首启 seed 插件集），**已有会话与工作区数据保留**——会话格式 v4 有完整迁移器链
  （`v0→v1→v2→v3→v4`），旧会话会被逐个升级读取。
- **profile 换代**：旧 profile 由壳自动换代（用户层文件优先保留），不需要手工删目录。
- **单实例**：与仍在运行的老版本**不能并行**（同一个单实例锁）；升级前请先退出旧版。
- **不买证书的既定取舍**：安装包未签名，Windows SmartScreen 会拦截，选择「仍要运行」即可。
