# v1.1.3 思灵（SSiD）

> 状态：**待发布**（2026-09-29）。两处实机反馈的修复 + 三个内置插件升到适配当前内核的版本。内核不变（`0.2.0-rc.1`）。

## 这一版修的是什么

### 标题栏背景宽度不稳定

标题栏左侧有一段透明「让位」，给 Windows caption 区里的可交互元素让路，宽度由 `measureGutter()` 现算。它的判据此前只有两条——「整块落在 caption 带内」+「本身窄（≤200px）」，两种元素因此漏了进来，让位被撑出好几倍：

- **横坐标没有受限**：`dsh-chat-rail` 的会话项宽仅 34px、轻松通过宽度判据，却落在 `right=698`——**宽度小不等于在左上角**。实测旧判据下 max right 在 0 / 1107 / 1149 / 1387 / 1428 之间反复跳，窗口 1280 宽时标题栏背景只剩 45%。
- **可见性没有受限**：chat-rail 在会话列过窄时给导航条加 `opacity: 0`——布局仍在，`getBoundingClientRect()` 照常返回真值，只看尺寸照样会把它当成占位收进来。

判据补成四维：整块落在带内 + 右边界 ≤200 + 宽度 ≤200 + 元素实际可见（`checkVisibility`）。同一页面下新判据的 max 恒为 0。

### chat-rail 盖住 DSH 的菜单

`@max-null/dsh-chat-rail` 0.6.7 → **0.6.8**。导航条与 DSH 的下拉菜单、tooltip 同为 `z-index: 100`，而导航条是挂到 `body` 末尾的浮层——同层级时 DOM 靠后者在上，于是菜单被压住。导航条降到 90（仍高于侧栏 30 与 dockkit 70），只让菜单赢。

## 内置插件升级

| 插件 | 从 | 到 |
|---|---|---|
| `@changfenhuang/dsh-genui` | 0.11.2 | **0.11.3** |
| `dsh-dream-skin` | 9.27.1 | **9.29.0** |
| `@max-null/dsh-chat-rail` | 0.6.7 | **0.6.8** |

前两个的新版本自行声明了覆盖当前内核（`0.2.0-rc.1`）的 peer 范围。内核按 peer 声明逐个校验 bundle，不满足时会**静默跳过整个 bundle**——不报错、不进「未激活」列表，只让等它服务的插件一直挂起。

这道门同时前移到打包期：随包插件集现在按内核自己的判据（`evaluatePluginCompatibility`）逐个校验，任何与内核不兼容的 bundle 会让**打包失败**，而不是等到用户机器上才表现为「某个插件的服务一直等不到」。

## 升级说明

- **覆盖安装即可**，会话、工作区与配置保留。内核未变，不需要迁移。
- **内置插件无需手动更新**：上表三个插件的升版本已随包内置。
- **单实例**：与仍在运行的其他版本不能并行；升级前先退出旧版。
- **不买证书的既定取舍**：安装包未签名，Windows 的「无法验证发布者」提示点「运行」即可。
