# 安装卡死「思灵无法关闭」+ 安装/部署步骤可视化

日期：2026-08-17
状态：✅ 已完成（v0.1.4 已发布，用户实测确认「棒」）

## 现象（用户实测）

已安装 v0.1.2，运行 v0.1.3 安装包：NSIS 进度条约 50% 处报「思灵无法关闭」后卡住。

## 根因推测

- 旧版卸载阶段（NSIS 安装进度中段 ≈ 50%）执行 v0.1.2 的 uninstaller；
  该卸载器检测到「思灵」进程正在运行 → 尝试关闭失败 → 弹「思灵无法关闭」并等待。
- **为什么关不掉**：壳的 close-to-tray 逻辑（`win.on('close')` preventDefault + hide）
  拦截了卸载器发送的 WM_CLOSE——窗口只是藏进托盘，进程不退，卸载器永远等不到退出。
- 触发前提是用户开着思灵安装新版（常见操作路径）。

## 方案

### 1. 安装器侧治本（NSIS include 脚本）

`shell/build/installer.nsh` + `package.json` `nsis.include`：

- `customInit`：`taskkill /F /IM 思灵.exe /T` 强杀运行中的思灵（close-to-tray
  使优雅关闭失效，强杀是唯一可靠路径；会话数据为增量持久化落盘，风险低）。
  仅杀「思灵.exe」，不碰 electron.exe（避免误伤其他 Electron 应用）。
- `ShowInstDetails show`：强制展开安装详情区。
- `DetailPrint` 步骤清单：① 关闭运行中的思灵 → ② 卸载旧版 → ③ 复制程序文件
  → ④ 注册与快捷方式 → ⑤ 完成。卡住时详情区最后一行即卡点（用户可拍照反馈）。

### 2. 首启部署阶段同步加步骤列表（splash）

- `splash.html`：新增步骤清单 UI + `window.__setStepList(items, current)`
  （完成项打勾、当前项高亮）。
- `main.mjs`：启动阶段清单（初始化 → 部署运行环境（解压/校验/交换）→
  启动内核 → 加载界面 → 就绪），各节点更新当前步；失败时停在失败步。

### 3. 版本与交付

- bump `0.1.4`，release notes 记修复；打包出新安装包供用户实测（本机需
  先 `prepare-runtime` 重建 dsh-runtime.tar.gz 归档）。

## 最终实现（NSIS 侧，四轮迭代收敛）

1. **杀进程**：customInit + customCheckAppRunning 双处 `taskkill /F /IM 思灵.exe /T`。
2. **详情区展开**：customCheckAppRunning 内 `SetDetailsView show`（Section 合法指令，
   实测可覆盖 common.nsh 的顶层 `ShowInstDetails nevershow`）。
3. **清单**：LVM_INSERTITEMW 直插 SysListView32（1016）——nevershow 下 DetailPrint
   被运行时丢弃，必须绕过打印机制。
4. **步骤推进**：NSIS wiki DetailUpdate 方案——LVM_SETITEMTEXT 更新列表最后一项 +
   WM_SETTEXT 同步状态标签（1006），每次现取句柄、寄存器 Push/Pop 保护；
   尾部分步 Sleep 1.2s 防 finish 页秒切。

## NSIS 定制坑合集（全部实测）

1. **ShowInstDetails 的合法上下文是文件顶层**（本地 makensis 探针实测）：
   .onInit / Section / 普通 Function 全部编译报错，**顶层（文件作用域）合法**，
   语义为「详情区默认展开」。MUI 页面回调绑定也救不了（NSIS 单遍编译，
   include 编译时还看不到后续模板的页面绑定）。
2. **SetDetailsView show 是 Section 内合法指令**（官方文档：sections can
   override the default details view）——但只在 customInstall（文件复制后）
   时机，救不了更早的卸载卡死点，仅作保险。
3. **模板在非静默安装时执行 SetDetailsPrint none**（installSection.nsh 第 6 行）
   会吞掉 Section 内的 DetailPrint——customInstall 里必须 SetDetailsPrint
   textonly 恢复。
4. **customInit（.onInit）的 DetailPrint 会缓冲进详情区**，instfiles 页显示时
   呈现——因此清单在 .onInit 打印，卡死在卸载步（customInstall 之前）时
   用户也能在展开的详情区看到「开始 [2/5] 卸载旧版本」这一行即卡点。
5. **卸载器构建同样 include 本文件**：顶层指令需 !ifndef BUILD_UNINSTALLER
   隔离；宏只定义不展开则无影响。
6. **打包偶发卡死**：signAndEditExecutable 时 Defender 锁 elevate.exe →
   electron-builder「waiting for unlock」循环，实测 5-20 分钟自动解锁后
   继续成功；处置：等待或杀进程清理 dist-electron 重跑。

  的 stdio 从 inherit 改为 pipe 或加 detached 处理**（候选改进）。
