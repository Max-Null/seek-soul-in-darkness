# 安装卡死「思灵无法关闭」+ 安装/部署步骤可视化

日期：2026-08-17
状态：进行中

## 现象（用户实测）

已安装 v0.1.2，运行 v0.1.3 安装包：NSIS 进度条约 50% 处报「思灵无法关闭」后卡住。

## 根因推测

- 旧版卸载阶段（NSIS 安装进度中段 ≈ 50%）执行 v0.1.2 的 uninstaller；
  该卸载器检测到「思灵」进程正在运行 → 尝试关闭失败 → 弹「思灵无法关闭」并等待。
- **为什么关不掉**：壳的 close-to-tray 逻辑（`win.on('close')` preventDefault + hide）
  拦截了卸载器发送的 WM_CLOSE——窗口只是藏进托盘，进程不退，卸载器永远等不到退出。
- 触发前提是用户开着思灵安装新版（常见操作路径）。

## 方案

### 1. 安装器侧治本（NSIS include 脚本）

`shell/build/installer.nsh` + `package.json` `nsis.include`：

- `customInit`：`taskkill /F /IM 思灵.exe /T` 强杀运行中的思灵（close-to-tray
  使优雅关闭失效，强杀是唯一可靠路径；会话数据为增量持久化落盘，风险低）。
  仅杀「思灵.exe」，不碰 electron.exe（避免误伤其他 Electron 应用）。
- `ShowInstDetails show`：强制展开安装详情区。
- `DetailPrint` 步骤清单：① 关闭运行中的思灵 → ② 卸载旧版 → ③ 复制程序文件
  → ④ 注册与快捷方式 → ⑤ 完成。卡住时详情区最后一行即卡点（用户可拍照反馈）。

### 2. 首启部署阶段同步加步骤列表（splash）

- `splash.html`：新增步骤清单 UI + `window.__setStepList(items, current)`
  （完成项打勾、当前项高亮）。
- `main.mjs`：启动阶段清单（初始化 → 部署运行环境（解压/校验/交换）→
  启动内核 → 加载界面 → 就绪），各节点更新当前步；失败时停在失败步。

### 3. 版本与交付

- bump `0.1.4`，release notes 记修复；打包出新安装包供用户实测（本机需
  先 `prepare-runtime` 重建 dsh-runtime.tar.gz 归档）。

## NSIS 定制三连坑（实测记录）

1. **ShowInstDetails 是 page-callback-only 指令**：.onInit、Section、普通 Function
   三种上下文全部编译报错（`not valid in Function/Section`）。官方文档指明
   section 内应改用 `SetDetailsView show` 覆盖详情区显示状态。
2. **卸载器构建同样 include 本文件**：无 MUI_PAGE_INSTFILES 的孤立页面回调
   Function 会编译失败，页面绑定需 `!ifndef BUILD_UNINSTALLER` 隔离（最终
   方案改用 SetDetailsView 后该隔离不再需要，宏只定义不展开即无影响）。
3. **customInstall 展开在 installSection.nsh 的 Section 内**：SetDetailsView /
   DetailPrint 合法；customInit 展开在 .onInit（installer.nsi 80 行），
   nsExec 静默执行 taskkill。

## 本机重建归档（prepare-runtime）记录

- 本机 node v26.2.0 / pnpm 11.21.0 / bsdtar 满足要求（DSH_NODE + PNPM_CMD 显式指定）。
- `pnpm add 缺失 peer` 的 spawnSync 报 ETIMEDOUT：pnpm 实际已装完（node_modules
  完整），但子进程句柄未及时关闭导致 spawnSync 等待 10 分钟超时。处置：手动补
  `.runtime-version`（0.1.4-0.1.0-rc.6）+ 手动 `tar -czf`（123.6 MB）+ 删源目录，
  与脚本第 6/7 步等价。**构建机下次跑 prepare-runtime 若复现，考虑把 runPnpm
  的 stdio 从 inherit 改为 pipe 或加 detached 处理**（候选改进）。

## 备查

- electron-builder NSIS 钩子宏：customInit（installer.nsi .onInit）、customInstall
  （installSection.nsh Section）；DetailPrint 输出到安装详情区。
- 卸载器关不掉 app 的根因是 close-to-tray 拦截 WM_CLOSE——该行为对用户是特性，
  不改为监听安装器；由安装器侧强杀配合（taskkill /F /IM 思灵.exe /T）。
