## 坑与解法（复盘）

| 坑 | 现象 | 解法 |
|---|---|---|
| 官方 rc.1 依赖范围缺陷 | 若干子包 `>=0.1.2 <0.2.0-0` 匹配不到 rc.1 预发布 → 干净安装 NO_MATCHING（capture 装包被堵） | 插件侧 peer 精确 pin；闭包侧 overrides 强制 rc.1 |
| pnpm 11 单包 overrides 不生效 | 只在多包 workspace 根生效；单包 `overrides` 无效 | **junction 借链**：capture/node_modules → chat-rail/node_modules（+ tsconfig paths 5 个 @deepseek-ai/* 指向 chat-rail 实体）；vitest 同样借 deepseek-harness/nm |
| capture TS2717 webServer 重复 | 本地 `declare module` 增强与官方类型重复 | 删除本地增强（官方类型经 paths 解析） |
| MCP 管理列表为空 | dev profile patch `[]` | 澄清语义（列表 = loader 条目）后补 playwright；**非发布缺口**（模板本就预置 mcp-playwright 行） |
| dev 被归档回灌干扰 | 清预设 → 自动回灌 → 依赖报错死循环 | main.mjs 隔离设计（就绪信号 + dev 跳过部署） |
| 官方 rc.1 npm 发布链版本杂糅 | dsh 族存在 alpha.3/4/5/rc.1 多版本 | 全部显式 pin：插件 peer 精确、模板 overrides 强制、dev install 以 lockfile 固化 |
