## 一、设计要点回顾（读源码实证后确认）

| 通道 | 现状（v0.2.2） | 改后（0.3.0） |
|---|---|---|
| 状态 | `suggested\|auto\|suggest` | `suggested\|approved` + `injected: boolean`（二维） |
| 注入 | `list({status:'auto'})` 全量注入 | `list({status:'approved', injected:true})` |
| confirm | `setStatus(id,'auto')` | `setStatus(id,'approved')`（审核语义，不触发注入） |
| 检索 | memory_search 任意 status | 不变（含 suggested，已确认决策） |
| RPC | list/search/confirm/forget/reload | + `setInjected(id, boolean)` |

**迁移规则**（读旧 schema 兼容转换，不重写文件）：
- 旧 `auto` → `{ status:'approved', injected:true }`（行为不变）
- 旧 `suggest` → `{ status:'suggested', injected:false }`
- 旧 `suggested` / 缺 injected → `{ status:'suggested', injected:false }`
- `approved` + 缺 injected → `injected:false`（新写路径）
