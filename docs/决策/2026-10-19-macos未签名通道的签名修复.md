# macOS 未签名通道：签名改由 afterPack 深签

> **状态**：已落地并经 CI 验证（2026-10-19）。
> **上游**：[`release-notes-v1.1.8.md`](../release-notes-v1.1.8.md)、skill `ssid-release` §5「mac 侧四个坑」。
> **本文要回答的问题**：v1.1.8 的 mac 构建连续两次挂在 `codesign --verify --deep --strict` 上，是偶发还是确定性？该怎么修？

---

## 一、现象

`build-mac.yml` 在 tag `v1.1.8` 上失败两次（run `39144371332` 及其 rerun），都停在打包步骤，报错只有一句：

```
⨯ Command failed: codesign --verify --deep --strict --verbose=2 .../思灵.app
```

`@electron/osx-sign` 把真正的错因吞掉了，只留这一行。

## 二、定位

workflow 里本来就有一步 `if: failure()` 的诊断（打印事后 verify、Mach-O 普查、重签后立刻 verify），它给出了关键读数：

| 读数 | 值 |
|---|---|
| Mach-O 普查 | `总数=141 未签名=8` |
| 未签名的 8 个 | `runtime/primary-runtime/dependencies/python/lib/python3.12/site-packages/**/*.so`、`runtime/primary-runtime/dependencies/pnpm/dist/node_modules/@reflink*` |
| 事后重跑同一条 verify | 第一次（run 39144371332）**通过**，第二次（rerun）**失败** |

**根因**：`electron-builder-config.mjs` 的 `mac.signIgnore` 有意排除了 `runtime/primary-runtime` 与 `ssid-plugins`（为了保留上游原生签名），但那些目录里的 python `.so` 与 pnpm `@reflink` **本来就没有签名**。`@electron/osx-sign` 签完固定跑的那次 `--deep --verify` 会递归检查它们，于是必败。

第一次「事后重跑却通过」是诊断步骤的假象：那里验的是同一个 app 但在**不同的系统状态**下，与打包时那次不是同一条件。**2026-09-29 据此把这条记成「偶发（事后重跑必过）」是错的**，v1.1.8 的两次连续失败推翻了它。

## 三、修法

```diff
- identity: unsigned ? '-' : macOSSigning?.signingIdentity,
+ identity: unsigned ? null : macOSSigning?.signingIdentity,
```

```js
// afterPack 里，未签名 mac 分支新增：
if (context.electronPlatformName === 'darwin' && unsigned) {
  const appBundle = join(context.appOutDir, `${context.packager.appInfo.productFilename}.app`)
  await promisify(execFile)('codesign', ['--sign', '-', '--force', '--deep', '--options', 'runtime',
    '--entitlements', fileURLToPath(new URL('./macos-entitlements.plist', import.meta.url)), appBundle])
}
```

- `identity: null` 让 electron-builder **完全跳过签名**，也就不再跑那次固定的 verify。
- `afterPack` 用 ad-hoc 身份对**整个 `.app`** 做一次 `--deep` 签名，把被 `signIgnore` 排除的 8 个 Mach-O 一并签上。
- **有签名构建的路径完全不变**：`identity` 仍取发布身份，`afterSign` 里的验证照旧。

| 项 | 读数 |
|---|---|
| run | `39149877010`（tag 重推触发） |
| 结论 | `success`，19 分 17 秒 |
| 产物 | `ssid-1.1.8-mac-arm64-unsigned.dmg` 397.3 MB，已挂到 Release `v1.1.8` |

## 五、遗留

- 这条修法在 `apps/desktop/scripts/electron-builder-config.mjs`（壳代码，fork 分支 `ssid-desktop-fork`，commit `89725dd9`），**不在 DSH 源码里**，所以不违反「DSH 源码只引用不改」。
- 未签名包仍会被 Gatekeeper 拦截（既定取舍），**本条只保证打包链能产出产物**，不代表 mac 版可直接分发。
- 诊断步骤（workflow 里的 `if: failure()` 那段）保留：下次再挂在签名上，它能直接给出未签名文件的清单。
