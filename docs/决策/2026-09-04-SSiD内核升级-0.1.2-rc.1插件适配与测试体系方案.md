# SSiD 内核升级 0.1.2-rc.1 插件适配与测试体系方案（2026-09-04）

## 背景

- 官方发布 DSH 内核 **0.1.2-rc.1**（npm 族 `@deepseek-ai/dsh@0.1.2-rc.1` 等，含本地源码 tag `dsh-v0.1.2-rc.1`）。
- SSiD 上一版（v0.1.17）内核为 0.1.2-alpha.2；本版目标：**升级 rc.1 并完成自研插件适配后发版**。
- 期间评估过 alpha.4：实测大历史会话加载卡死（净负收益），回滚 alpha.2；最终定稿 rc.1。

## 内核接法

- 源码模式：deepseek-harness checkout 固定 `dsh-v0.1.2-rc.1` → `prepare-runtime.mjs` 从 `apps/cli/package.json` 自动读取 `DSH_VERSION=0.1.2-rc.1`（单一来源）。
- 闭包版本锁定：`profile-template/pnpm-workspace.yaml` overrides 214 条 `@deepseek-ai/dsh-*` 全局 pin（v0.1.17 时代为 alpha.2，本版改 `0.1.2-rc.1`），防聚合包/子包版本漂移。

## 风险与对策：官方 rc.1 依赖范围缺陷

- 现象：官方若干子包依赖声明 `">=0.1.2 <0.2.0-0"`，而 rc.1 是预发布版本（`0.1.2-rc.1 < 0.1.2`），semver 范围匹配不到 → 干净安装 NO_MATCHING。
- 对策（分层）：
  1. 归档闭包：overrides 214 条强制 rc.1 家族（如上）。
  2. 自研插件：consumer 侧按需精确 pin 官方 peer（例：`@max-null/dsh-chat-rail@0.6.0` peer `dsh-settings: "0.1.2-alpha.5"` —— rc.1 发布链中 settings 的最新可解析版；`dsh-session-projection: "^0.1.2-alpha.2"` 范围可覆盖 rc.1）。
  3. 开发装包：junction 借链 + tsconfig paths（见执行复盘）。

## 插件适配范围与范式

- 对象：@max-null/dsh-chat-rail（0.6.0）、@max-null/dsh-capture（0.3.0）、@max-null/dsh-quick-toolbar（0.8.6）。
- rc.1 设定 API 形态：官方 `settings` 宿主三段式（host `settings.installSection(ctx, NS, Config(schemastery z), config, {setSource,onChange})` + client `settingsScope.bind({namespace:NS})` + `settings.plugin.item` keyed 卡片，卡片样式 = 官方白卡 12px、header/desc、IconChevronDownOutline14、cardOpen 底 layer-2、家族开关 40×22）。
- 迁移原则（用户拍板）：**「把设置迁移到新位置」**——三个插件设置一律迁到 settings 新卡片；参数少的用内置卡片（ppp 三段式），参数多的保留独立页（plugin-center / memory-manage 先例）。
- 非设置项：quick-toolbar 悬浮球按官方设计方案、侧栏/底栏图标用 better-sidebar 官方同款（框+实心内条）。

## 测试体系（tests/plugin-adapt，纳入 shell workspace）

- 定位：SSiD 插件实机适配回归（连 dev 运行中实例，默认 CDP `127.0.0.1:9222`）。
- 断言四层：
  - L1 Boot 健康：页面就绪、无 `Failed to load plugins`、console 0 error/exception（导航前注册捕获）。
  - L2 界面契约：`data-slot`/`aria-label` 锚点、`style[data-plugin]` 注入、布局顺序（横向 bbox 比较）。
  - L3 功能可用：真实交互闭环（点击 → toast/结果）。
  - L4 样式契约回归：按钮行 computed style 快照 vs 基线 JSON（`pnpm baseline` 更新；像素截图路线判定不可行，见 README 已知坑）。
- 基线入库：签名变化需人工确认后重生成；截图用例排在 toast 触发用例之前、`caret:'hide'`。
- 服务面：L1 全绿为发版门槛（typecheck + test 全绿）。

## 发布面

- 三个自研插件：npm 发布（用户手动 F2A）+ vendor 三处同步（plugins 源 / profile-template/vendor / dev profile vendor；`git diff --no-index` 与 MD5 双核对）。
- 归档：`prepare-runtime.mjs` 重建（官方 registry，不设 SSID_REGISTRY——rc.1 已上官方 npm）。
- 老用户升级：版本指纹不一致 → 自动重部署（约 30 秒可跳过）。
