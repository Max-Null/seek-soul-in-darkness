# DSH 原生配置页样式基准（family 插件统一规格）

> 来源：deepseek-harness 源码 `packages/client/ui-settings-general/SettingsRoot.module.css`、
> `ui-settings-plugins/PluginsSettingsSection.module.css`、`fields.module.css`、`PluginCard.module.css`、
> `ui-agent-preset/AgentPresetSection.module.css`、`ui-primitives/Button.module.css`、`Pill.module.css`。
> 所有 CSS 值均为源码原文，任何家族插件不得自创规格。

## 设置外壳（弹窗，通常不需要改）

- 面板：800×min(800px, 100vh-48px)，radius **24**，bg `--dsw-alias-bg-layer-2`，`--dsw-shadow-lv3`。
- 左导航：宽 188，padding 22/12/0；标题「设置」16/500 lh24；导航项 h40 r12 padding 9 16 9 12，14/400，
  选中 `--dsw-specific-sidebar-nav-item-active`，hover `--dsw-specific-sidebar-nav-item-hover`。
- 内容区 header h54；内容 padding 0 24 24；关闭钮 28×28 r28。

## 页面骨架（设置页 Section 通用）

- section：`max-width: 760px`（Agent 预设页 720px），flex column gap **12**。
- 页面标题 heading：**font-size 18 / weight 600**（原 family 自创 16px 已作废）。
- 页面描述 intro/subtitle：**13px，color label-tertiary**（原 family 自创 secondary 已作废）。
- 分组题头 groupHead：12/600，uppercase，letter-spacing .06em，color label-tertiary；组间距 20。

## 卡片（列表卡与网格卡统一）

- 卡：border 1px `--dsw-alias-border-l2`，bg **`--dsw-alias-bg-layer-3`**，radius **12**，
  hover `border-color: --dsw-alias-label-dimmed`，transition .16s。
- 卡头：padding **14px 16px**，gap 12（grid 卡 cardMain padding 14 16 12，gap 8）。
- 卡名 name：**15px / 600**，line-height 1.4。
- 卡描述 description：**13px**，label-tertiary（列表卡）或 label-secondary + line-clamp 4（网格卡）。
- 卡脚 cardFoot：border-top l2，padding 6px 10px，gap 2。
- 网格：grid-template-columns repeat(auto-fill, minmax(268px, 1fr))，gap 12，auto-rows 1fr。

## 徽标 badge（胶囊统一）

- 胶囊：border-radius **999px**，padding 1px 8px，**font-size 11 / 500**，line-height 17px。
- 中性：border l2 + label-tertiary（预设卡）或 bg `--dsw-alias-bg-module-platform` + label-secondary（字段）。
- 强调（in use）：bg `--dsw-alias-label-primary`，color `--dsw-alias-bg-layer-3`。
- 危险/错误：bg `--dsw-alias-state-error-primary`，color bg-layer-3。
- 官方/业务强调：bg `--dsw-alias-state-business-tertiary`，color `--dsw-alias-state-business-primary`。
- （Pill 组件：h24 r12 12px/18，bg-layer-2，label-secondary —— 与 badge 并列场景用 Pill。）

## 按钮

- primitives Button：胶囊 r18，h36 padding 0 14，14px/22；sm 变体 h28 r14 padding 0 10 12px/18。
  primary = `--dsw-alias-button-primary-fill` + `--dsw-alias-label-primary-foreground`；
  outline = border l2 透明底；hierarchy 用 hover `--dsw-alias-interactive-bg-hover`。
- 卡内操作（save/discard）：**r8，padding 5px 14px，13px/1.5**；
  discard = border-l2 + label-secondary；save = bg `--dsw-alias-label-primary` + color bg-layer-3。
- 图标按钮：padding 6，r7，color label-tertiary，hover bg-layer-1 + label-primary；
  focus-visible outline 2px brand。

## 字段/表单（卡片展开区）

- field：padding 12px 0，flex column gap 6；field+field 分隔线 `border-top l2`。
- 字段题头 head：gap 8；标签 label：**13px / 500**，line-height 1.5，label-primary。
- 输入框：**h34，r8，padding 0 12px，13px/1.5**，border l2，bg `--dsw-alias-bg-layer-3`，
  focus border `--dsw-alias-brand-primary`；placeholder label-dimmed。
- 提示 hint/错误：12px，tertiary / `--dsw-alias-label-error`。
- 重置 reset 链接：12px label-secondary，hover label-primary。

## 选项卡 tabs（插件配置页样式）

- tabs 容器：border-bottom l2，gap **22**，margin-top 2。
- tab：13px/20，padding **7px 1px 9px**，color label-tertiary，hover/active label-primary；
  active 下划线 2px l2（radius 2 2 0 0，bottom -1）bg label-primary；
  focus-visible outline 2px `--dsw-alias-state-business-primary`。

## 开关 switch（家族自定，保持统一）

- 40×22 r11；track off = **`--dsw-alias-border-l4`**（浅色主题 rgba(0,0,0,.16) 灰、暗色 rgba(255,255,255,.2) 灰，
  两主题均与白钮有对比；不可用 `bg-module-platform` — 浅色主题下 ≈ rgb(245,246,247) 纯白，off 开关完全隐形），
  on = `--dsw-alias-state-business-primary,#4FC3F7`；
  knob 16×16 白 #fff；margin-left 2→22（或 left 3→21）；transition .15s。
- DSH 原生无 knob 开关（无 Switch 组件），此为 SSiD 家族统一基准，勿再改动。
