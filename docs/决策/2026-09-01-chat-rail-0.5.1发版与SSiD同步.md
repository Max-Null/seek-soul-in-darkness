# chat-rail 0.5.1 发版与 SSiD 同步（2026-09-01）

## 背景

DSH `0.1.2-alpha.2`（SSiD v0.1.17 起的内核）把 Conversation 目标数据移出 Session 快照：
`session.getSnapshot()` 不再携带 `chat.nodes`，Chat 节点迁入 `uiConversation` 服务的
`'chat'` 视图目标（`ChatSnapshot.nodes` keyed store）。chat-rail 0.5.0 在新内核上
「点击导航跳转失效」：加载探测读死字段 → 翻页到 `hasMore` 耗尽仍放弃 → 不滚动
（`[chat-rail] jumpToMessage: node … not loaded after N page(s)`）。

## 修复与发版（dsh-chat-rail 仓库）

- `0c3b0de` fix：双数据通道适配——`uiConversation.binding(id).target('chat')` 优先，
  旧 `chat.nodes` Map 兼容回退；`jumpToMessage` 改用 `nodeOf` 实时探测；
  collect/tip 读取同步适配。新增 `tests/client-nodes.spec.ts`（11 例，34/34 全绿）。
- `b26ec57` release: v0.5.1（package.json + `docs/release-notes-v0.5.1.md`），tag `v0.5.1` 已推送。
- L1：typecheck ✅ / test 34/34 ✅；L2（web 环境用户实测）：跳转正常 ✅。
