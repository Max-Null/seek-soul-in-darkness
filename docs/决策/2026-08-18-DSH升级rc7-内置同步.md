- DSH 上游已发布 `0.1.0-rc.7`（npm latest），SSiD 内置闭包 pin 的是
  `0.1.0-rc.6`——按「DSH 跟进必须是显式决策」的既有约定，本次执行升级。

  2. MISSING_PEERS 20 个 `@deepseek-ai/dsh-*@0.1.0-rc.6` → rc.7
     （cordis-plugin-group@1.0.1 / cordis@4.0.0-rc.8 不动）

  由冒烟把关；precise pin 下不会漂移到其他版本。
