- `shell/assets/icon.png` 512×512：四角 A=64~255 深色不透明 → **方角**，需圆角透明。
- `assets/logo.png` 256×256：四角纯白不透明 → **白色方角**，需圆角透明。
- `shell/assets/tray.png` 32×32：托盘图标保持现状（圆角在托盘显示怪异）。

做法：
- PowerShell System.Drawing：圆角矩形 GraphicsPath 裁剪重绘，四角透明。
  - icon.png 圆角半径 100px（约 20%）；logo.png 半径 48px。
- `shell/assets/icon.ico` 重建：**PNG-in-ICO** 封装（Vista+ 标准，ICONDIR 头 +
  单条目 + 256×256 PNG 数据），避免 PNG→ICO 转换的 Defender 竞态（pitfalls #1）。
- 打包后 exe 图标/快捷方式随 icon.ico 生效（signAndEditExecutable 注入）。

## ICO 打包坑（实测记录，补充 pitfalls）

1. **手写 PNG-in-ICO 不被接受**：app-builder-bin 的 icon 转换工具不支持
   PNG-in-ICO 输入 → 转换静默失败 → `.icon-ico/` 缓存目录不生成 →
   getIconPath 回退默认图标 → resedit 解析空/异常 buffer 报
   「Offset is outside the bounds of the DataView」。
2. **手写 BMP-in-ICO（DIB 256×512 双高）同样不被接受**：转换工具仍拒绝
   （缓存目录不生成），报错同上。
3. **正解：win.icon 用 PNG**（electron-builder 原生 PNG→ICO 转换，历史
   路径一直可用；转换产物经 resedit 注入 exe）。Defender 锁竞态
   （pitfalls #1）为概率事件，重试可过。
4. **`.icon-ico/` 是转换缓存**：换图标源时旧缓存可能残留旧产物，排查时
   先删 `dist-electron/.icon-ico`。
