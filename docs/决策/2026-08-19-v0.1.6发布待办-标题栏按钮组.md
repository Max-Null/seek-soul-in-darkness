## 三、发布链路（按序执行，每步成功后进入下一步）

### 1. plugin-center：push + publish
```sh
cd D:\Project\dsh-plugin-center
git push origin main          # 推送 509d9f5 + 1833b58
npm publish                   # 发布 @max-null/dsh-plugin-center@0.1.7（需 npm token）
npm view @max-null/dsh-plugin-center version   # 确认 0.1.7
```
> 注意：pnpm-workspace.yaml 已把 0.1.7 加进 `minimumReleaseAgeExclude`，发布后立即 prepare-runtime 不会触发发布年龄检查。

### 2. 重跑运行环境归档（新装机闭包）
```sh
cd D:\Project\ssid\shell
node scripts/prepare-runtime.mjs
```
- 产物：`shell/dsh-runtime.tar.gz`（约 170MB，含 dsh-header-unify + plugin-center 0.1.7）
- 前置：Node ≥22.13（默认找 `D:\Program Files\nvm\v22.22.2\node.exe`）、pnpm 11.x
- 归档版本 `.runtime-version` = `0.1.6-0.1.0-rc.7-<指纹>`：版本 + 依赖 + vendor 指纹变化会触发老 profile 重部署

### 3. 重新打包安装版
```sh
cd D:\Project\ssid\shell
npm run pack
```
- 产物：`shell/dist-electron/思灵 Setup 0.1.6.exe`
- 验证 asar 含新标题栏：`btn-plugins` / `ssid:title:action`（打包后可选 grep）
