## 一、功能交付（均已用户实测 / 系统验证）

### 1. 会话存储隔离（SSiD 与手动 dsh web 彻底分家）
- 设置页「会话存储」卡片：开关（**预设默认开启**）、常驻计数
  （独立根/共享根/已载入）、载入原 DSH 会话、移除已载入会话（**B 方案：只删清单内**）、
  按需「重启思灵」行、统一操作反馈行；
- 载入 = 复制共享根会话 → 独立根（幂等：已存在跳过）；
- **workspace attach**：载入/已存在会话 attach 到 cwd 对应 workspace（侧栏分组即时可见）；
- 隔离开关状态 `~/.ssid/session-root.json`（isolated=开关，applied=启动生效值，
  kernel 回写）；**预设：无配置文件 ⇒ 默认隔离**（首次启动落盘显式配置）；
- 已载入清单 `~/.ssid/imported-sessions.json`（B 方案：移除只删清单内，新建会话保护）；
- `listNeedsRestart`（清单 mtime vs `SSID_BOOTED_AT`）持久判定重启提示行。

### 2. 插件更新三段式（dsh-plugin-center）
- 直装优先（99% 成功：纯 JS/新增包/未锁原生模块）；
- 撞锁（EPERM/EBUSY/rename）分流：SSiD（kernel 声明 `SSID_PENDING_CONSUMER=1`）
  → **npm pack 预下载** → pending 清单（`~/.ssid/pending-plugin-updates/index.json`）
  → **重启时 kernel boot 前安装**（无锁窗口）；官方 dsh web（无消费方）→ **指令复制弹窗**；
- UI：直装 toast + 「已更新待重启」卡片（点击弹重启确认）、多更新统一弹窗、
  busy 保护（进行中会话拦截）、WhatsNew 弹窗旧检查修复。

### 3. 可靠性修复（本轮） 
- 托盘「重启」`restartDsh` 作用域 ReferenceError（try 内 const → 提出去）；
- BOM 写坏 profile package.json（**教训：改 JSON 一律用 node，禁 PowerShell Set-Content**）；
- host 版本缓存假象（外部改版本后 listInstalled 旧值——重启应用可解，mtime 失效改进挂起）；
- 弹窗配色统一到 DSH 官方变量（`button-primary-fill` + `label-primary-foreground`）。
