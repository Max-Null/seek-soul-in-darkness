1. **合成配置**：`dsh --profile ssid --dump-config` 含三条——`# == dsh-context`（id: dsh-context）、`# == @changfenhuang/dsh-genui`、`# == dsh-context-doctor`（id: context-doctor）✅

3. **Peer**：无新增缺失——genui 的官方 peer（dsh-client-ui-conversation/ui-primitives/slots/llm/session/system-prompt/tools/invariants）经 semver 判定全部满足（0.1.1-rc.2 ∈ `>=0.1.1-rc.0 <0.2.0`），物理上在 node_modules 存在；`pnpm peers check` 报告的 missing 为 SSiD hoisted 布局的既有特征（官方 peer 不入依赖图，运行时由 cordis loader 按服务注入），与 chat-rail 先例同款，**prepare-runtime.mjs 的 MISSING_PEERS 无需补充**。
4. **JSON 合规**：模板与 dev profile 的 package.json 均通过 node JSON.parse 校验。

## 四、生效方式

- 开发环境：重启思灵（或当前 GUI 会话）后 ssid profile 加载三个插件。
- 发布环境：**需重建运行时归档**——`node scripts/prepare-runtime.mjs`（shell/ 目录；归档带 vendor 指纹，自动包含新 vendor 与技能），然后替换安装目录归档 → 下次安装/升级即开箱即用。
