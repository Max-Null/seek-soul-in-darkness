# 记忆面板刷新机制：外部编辑文件后重载存储

日期：2026-08-19
状态：进行中

## 用户实测问题

外部应用编辑记忆文件后，SSiD 记忆面板一直显示旧数据。

## 根因（源码确认）

- DSH `JsonStorageBackend`（storage-json）**打开时 loadAll 一次进内存**，
  之后读写走内存、写时 atomic 落盘——**无 watch、无 reload API**
  （packages/storage 全 grep reload 无匹配）。
- dsh-memory 的 `list()` 读 domain table（内存缓存）→ 外部文件编辑不感知。
- panels MemoryView 挂载时拉一次，无刷新按钮/可见性重拉。

## 修复

1. **dsh-memory 0.2.1**：`MemoryService.reload()`——关闭 domain 重开
   （facility.closeAll → 重新 open 两域），放弃内存缓存强制重读文件。
   - engine.ts 重构：facility/table 提为字段，init 与 reload 共用 openDomains()；
     关闭效应改为引用当前 facility。
2. **dsh-ssid-panels 0.1.3**：MemoryView 加「刷新」按钮（调 memory.reload
   → memory.list 重拉）；tab 可见时自动重拉（visible prop，与其他 tab 一致）。
   - host 端点：`memory.reload`（调 memory.reload?.() 后返回 list）。
3. 发布链：dsh-memory npm 0.2.1 → SSiD 依赖/豁免/缓存 → 归档 → 冒烟 → pack。
