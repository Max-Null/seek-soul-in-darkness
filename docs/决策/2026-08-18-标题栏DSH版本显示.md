# 标题栏显示 DSH 版本（官方版本通道占位符的壳层补齐）

日期：2026-08-18
状态：进行中

## 背景（用户调查结论）

- 官方版本通道存在但拿不到真实值：`host.describe`（api-proxy.ts:2865）
  硬编码 `version: '0.0.1'`（TODO 占位），apps/cli 的真实版本未流入。
- 结论：DSH 版本展示由 SSiD 壳层补齐——壳本来就读 DSH 运行时锚点。

## 方案

- **版本来源**：kernel.ts 的 `runtime.installAnchor`（source 模式 =
  apps/cli/package.json；bundled 模式 = @deepseek-ai/dsh/package.json）
  直接读其 `version` 字段，boot 时解析一次。
- **展示**：自绘标题栏「思灵」右侧副标题胶囊小字 `DSH 0.1.0-rc.7`，
  muted 色 + 细边框，跟随 titlebar 主题变量（主题同步已有机制）。
- **传递链**：kernel.ts `Kernel.dshVersion` → main.mjs titleBar 加载后
  executeJavaScript `__setDshVersion` → titlebar.html 元素 + titlebar.js setter。

## 验证

- [ ] dev 冒烟：kernel 返回 dshVersion 正确（source 模式 = apps/cli 版本）
- [ ] pack 成功；安装版显示 bundled 模式版本（@deepseek-ai/dsh 版本）
- [ ] 视觉：副标题不干扰拖拽区（brand 区域本就 drag）
