# 会话完成通知：窗口失焦时 Windows 通知 + 音效（fractal 行为移植）

日期：2026-08-18
状态：进行中

## 需求（用户）

每轮会话结束时，若窗口不活跃（最小化/被遮挡/切到其他应用），弹 Windows
通知「会话已完成，用时 mm:ss」并伴随音效——对齐 OC 桌面版 / fractal 行为。

## 可行性结论（DSH 事件面查证）

- **轮次完成钩子**：`session/event` 的 `turn/end`（root ctx 可监听，Scoped
  事件在 root 接收全部 session）；reason.kind === 'completed' 表示正常完成
  （aborted/blocked/error/max-tokens/interrupted 不通知）。
- **计时**：SessionEvent 自带 `time`（Unix epoch ms）——turn/start 记 Map，
  turn/end 差值即用时，无需自己计时。
- **窗口活跃**：Electron `win.isFocused() === false` 覆盖最小化/遮挡/切走。
- **通知**：主进程 Electron Notification（tray 已有先例，无浏览器权限问题）。
- **音效**：spawn PowerShell `[System.Media.SystemSounds]::Asterisk.Play()`
  （零资产；Notification silent 避免双响）。
- fractal 参考：showNotification(title, body) + durationMs（useStreamProcessor
  notifyReplyDone）；fractal 无显式音效（Windows 默认），SSiD 显式加 Asterisk。

## 设计（第一版边界）

- 文案：标题「思灵」，正文「会话已完成，用时 mm:ss」——不带会话标题
  （Session 类型无 title 字段；后续若需要从 session-title 插件读，再扩）。
- 全量 session 的 completed turn 都通知（含子代理）；窗口聚焦时不打扰。
- 通知失败静默（Notification.isSupported 门控；音效 spawn 失败吞掉）。
