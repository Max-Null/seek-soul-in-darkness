## 一、硬约束

新项目（DSH 基座版）的壳必须满足：

1. 窗口内是 **DSH 官方 Web UI 本体**，非仿制/自绘前端；
2. 能打包**独立安装包**（bundled Node.js + dsh CLI，用户免装 Node）；
3. 能加载 **DSH 插件 / 皮肤**；
4. Windows 优先；加分项：托盘常驻、自动更新、配置隔离、进程治理、可二次开发。

## 二、结论

| 角色 | 项目 | 依据 |
|---|---|---|
| **首选** | [anywhere-labs/deepseek-harness-desktop](https://github.com/anywhere-labs/deepseek-harness-desktop) | Electron / MIT / 5443★ / 当天活跃；官方 UI 本体 + 内置 dsh；**唯一提供文档化桌面插件 API**（`desktopProfiles` + `desktopPnpm`），插件市场「即将推出」；macOS + Windows（无 Linux） |
| **备选** | [bruc3van/dsh-desktop](https://github.com/bruc3van/dsh-desktop) | Electron / MIT / 31★；「官方 UI 本体」定位最纯粹；SHA-256 更新校验 + 进程治理 + 智能复用已有 dsh；macOS + Windows |
| Windows 候补 | [ChisaAlter/Deepseek-Harness-Desktop](https://github.com/ChisaAlter/Deepseek-Harness-Desktop) | 84★；插件市场 + 主题 + 远程；Windows 特性强 |
| Windows 候补 | [myYangyunfan/dsh_desktop](https://github.com/myYangyunfan/dsh_desktop) | 265★；功能最多但偏产品化 |

**首选理由**：`anywhere-labs` 是唯一把「二次开发」做成一等能力的——文档化桌面插件 API 意味着分形的差异化功能除了做 DSH 插件，还可以走壳的插件 API，扩展面最宽。

## 三、否决项（勿作壳基础）

| 项目 | 原因 |
|---|---|
| `zouyuxuan122/Deepseek-Harness-EAC`（223★） | **无 LICENSE 文件**（README 谎称 MIT），皮肤混用 CC BY-NC-SA 4.0 禁止商用 → 一票否决 |
| `xiincs/deepseek-harness-desktop` | 「内置 Node」描述与 README 矛盾（README 明示从 PATH 定位 node）→ 不满足「免装 Node」硬需求 |
| `kelomina/deepseek-harness-wui` | 自绘前端，非官方 UI 本体 |
| `ipfred/deepseek-harness-app`、`LisiChen0`、`JustGenius-s` | 无实质内容 / 近空壳 |

## 四、风险

1. **停更风险整体存在**：生态处 2026-08 爆发期，壳强耦合 dsh rc 迭代，任一壳都可能随 dsh 升级漂移。
2. **首选壳无 Linux**：若分形 2.0 未来要 Linux，需另寻或自补。
3. **插件市场未落地**：`anywhere-labs` 的插件市场标「即将推出」，现阶段以 DSH 原生插件为主。

## 五、下一步

1. 拉取 `anywhere-labs` 跑通「DSH 官方 GUI + 壳 + dsh-memory/dsh-chinese-thinking」最小闭环。
2. 若首选壳不满足，回退 `bruc3van`（最纯粹的官方 UI 本体 + 安全加固）。
