## 1. 升级步骤（用户侧执行）

```powershell
# ① 准备：确认干净 + 取最新官方引用
cd H:\MaxNull\WorkStation\DSHfork
git status                                   # 期望干净（已核实）
git fetch origin
git tag -l 'dsh-v0.1.2*'                      # 应有 dsh-v0.1.2-rc.1

# ② 切到 rc.1（detached，与官方 checkout 同习惯）

# ③ 依赖对齐（rc.1 分支 lockfile，400+ 包，约几分钟；npm/pnpm 均可——
```

## 4. 风险与回滚

- **回滚**：`git checkout master && pnpm install --frozen-lockfile` 后重启原命令即可（DSHfork 干净，无代码迁移）。
- **注意**：升级后 DS 的会话数据/工作区配置不变（工作区根 `H:\MaxNull\WorkStation` 独立于 checkout）。
- **web 认证**：rc.1 与 alpha.5 均带 token 认证——若历史脚本/书签使用裸 URL，需改用启动日志打印的带 token URL（SSiD smoke-ui 的 `--cdp` 模式即为此设计）。
- **三环境纪律**：web(3080) = 当前会话主体——**升级窗口内不要启用本会话重启 DSH 的操作**；如果 3080 升级后需要重启，由用户在外部操作，本会话不主动调用。
