# 决策：消息导航自研，放弃第三方 rail 插件

> 日期：2026-08-18
> 状态：已决策
> 决策人：MaxNull
> 触发：实测 `dsh-chat-timeline@0.1.2`（jjxjjjjiik-bot）与 better-sidebar 共存后的体验缺陷
> 关联：`docs/决策/2026-08-16-社区插件评估-better-sidebar与OpenViking.md`、fractal `ChatTimelineNav` 设计（fractal/docs/设计/会话列表优化-设计方案.md 4.5）

---

## 〇、决策

**会话面板消息导航（右侧 rail）自研**，作为 `@max-null` 全家桶新插件（暂定名 `dsh-chat-rail`，见设计文档），不再评估/采用第三方 rail 插件。

## 一、背景

### 1.1 调研结论（2026-08-18，3 个 subagent + awesome 清单实测）

- awesome-dsh-plugin 中"会话面板消息/回合导航"方向**已是重度红海**，至少 15 个同款插件。
- 深度评估 8 个核心候选：`dsh-chat-timeline`（npm 0.1.2）、`dsh-message-preview`、`dsh-chat-index-rail`（npm 0.1.1）、`dsh-plugin-msg-nav`（v0.2.0）、`dsh-codex-timeline`（npm 0.3.2）、`dsh-turn-rail`（npm 0.1.0）、`dsh-session-timeline`（npm 1.0.1）、`dsh-milestone`（npm 0.6.0）。
- 关键共性风险：都依赖 DSH 内部 slot/投影契约，DSH 升级（rc.8+）可能全部失效；功能高度重叠，左右 rail 同屏互相干扰。

### 1.2 实测结论（dsh-chat-timeline@0.1.2 装入 ssid profile 实测）

功能上**不冲突**（它注入 `conversation.input.dock`，better-sidebar 用 `conversation.chat.turnTail` + CSS margin 挤压，槽位不重叠），但有两个体验缺陷：

1. **动画时序错位**：rail 用 `right: rightOffset` 定位，靠 ResizeObserver + MutationObserver + 2s 轮询跟随聊天区右缘。better-sidebar 展开时给 `#root` 加 `margin-right` CSS transition，rail 跟随滞后 → "边栏先展开、滚动条/rail 后移"的错位感。这是结构性时序问题。
2. **可见性差**：折叠态 rail 仅 34px 宽，指示线 8×2px、颜色 `rgba(0,0,0,.16)`，白色背景下几乎不可见。

## 二、决策理由

1. **代码简单**：核心就是"用户消息锚点投影 + 右侧指示条 + scroll spy + 点击跳转"，参考 dsh-chat-timeline 实现（431 行 client.js）完全可控。
2. **冲突可自处理**：SSID 还会继续加插件（better-sidebar 生态、excel-panel、video-preview 等），自研后任何布局/动画冲突都能自己修，不依赖上游。
3. **SSID 全家桶**：作为 `@max-null/dsh-*` 新成员进预制清单，与 memory/guardian/habit 同体系，品牌壳可统一皮肤。
4. **一劳永逸**：第三方 rail 的共性风险（DSH 契约漂移、红海同质化）在自研下由自己掌控。

## 三、技术方案要点（详见插件设计文档）

- **定位**：rail 定位不用"跟随聊天区 rect"，改用跟随 better-sidebar 的 CSS 变量 `--dsh-sidebar-width`（`#root { margin-right: var(--dsh-sidebar-width) }`），rail `right: calc(var(--dsh-sidebar-width, 0px) + 12px)`，与边栏共享同一 transition → 动画天然同步，消除时序错位。
- **可见性**：指示条加粗加深（按 SSID 品牌色），折叠态有底色/描边，hover 展开预览。
- **架构**：host 半端 `sessionProjections` 投影全量用户消息锚点（含 preview），client 半端 `conversation.input.dock` 注入。
- **兼容策略**：优先支持 better-sidebar 的 CSS 变量；其它右栏插件（如未来新增）预留 CSS 变量扩展位。

## 四、影响与回滚

- ssid profile 中已装的 `dsh-chat-timeline` 在自研插件就绪后**移除**（package.json dependencies + bundles 两处）。
- 回滚：自研插件开发失败时，可恢复 dsh-chat-timeline（依赖与 bundle 声明已记录于 2026-08-18 环境记忆）。
