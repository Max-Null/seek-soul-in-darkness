# SSiD 压缩阈值 0.8→0.6：决策与实测记录（2026-08-16）

## 决策

DSH 官方 compaction-basic 默认 `thresholdRatio: 0.8`——上下文到窗口 80% 才触发压缩。
实测确认此时超长上下文已导致模型注意力涣散。SSiD 的 ssid-double-star preset 改为
**`thresholdRatio: 0.6`**（60% 触发），`retainRatio` 保持官方默认 0.16（尾部原文保留比例）。

同时补齐 preset 此前完全缺失的 compaction group——web bundle 禁用了 host 层的
compaction-basic（`disabled: true`），压缩由 preset 决定挂不挂，SSiD 的 preset
没挂等于没有自动压缩。group 内容对齐 official standard：compaction-basic +
command-compact + tool-result-pruner。

## 实测结果（三层验证，2026-08-16）

### 2. 行为层（mock adapter，无 key）

### 3. 真实端到端（真实 DeepSeek V4 Pro + 真实 API）

```

```

摘要质量合格：三组信息文本的关键事实全部保留（SSiD 定位、三层架构、
dsh-memory 插件、阈值决策本身）。

## 顺带修复

SSiD preset 挂载此前会失败：DSH 升级后 schema 新增必填字段
（`tool-fs-search.sampleOverCapGlobResults`、`tool-todo.allowParallelInProgress`），
已对齐 standard 补上。

## 后续注意事项

- preset 文件有两个副本：仓库 `presets/ssid-double-star/`（版本管理）与
  `~/.dsh/.agent-presets/ssid-double-star/`（DSH 实际读取）。改动需同步 + 重启。
- DSH 升级后跑一遍配置层验证（挂载 preset + 读 compaction 服务），schema 变化
  会让 preset 静默断掉。
- 0.6 是首轮设定值，实测若仍感太晚可下调（下限受 retainRatio 约束：
  thresholdRatio 必须 > retainRatio）。
