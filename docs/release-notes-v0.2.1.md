# v0.2.1 发布说明（2026-09-07）

## 新增预制

- **dsh-wechat 0.9.1（微信桥）**：把 DSH 变成你的手机第二客户端——微信扫码绑定（腾讯 iLink 官方协议）即可收发消息、切会话/工作区/模型、远程审批与文件回传；单用户模式，默认关闭（不扫码不激活）。**注意**：项目非腾讯官方（MIT 开源），建议微信小号绑定。
- **CodeGraph MCP 0.20.1（语义代码图）**：MCP 管理页可见（与 playwright 并列）——代码索引工具（callers/impact/上下文分析）。**首次使用可能需要联网下载模型**；内存小于 1.5GB 时自动降级 graph-only 模式；索引目录默认用户主目录，可在 MCP 管理面板修改。匿名遥测已默认关闭。

## 修复与护栏

- **升级部署不再覆盖用户层**（v0.2.0 发现问题）：安装版升级时若用户已自装插件/自定义 MCP 预置，部署前与归档基线合并（用户增量保留），并带防误删护栏（profile-merge 逻辑 + 13 条回归测试）
- **模板 pin 精确化**：dsh-wechat `0.9.1`（精确）——模板全依赖精确形态，杜绝自动漂移
- **compat 修正**：codegraph 引擎随包安装（缺失时 MCP 表可见但连接失败——发布前已断言检查）

## 交付形态新增

- **zip 免安装版**（`ssid-shell-0.2.1-win.zip`）：解压双击即用（与安装版同一运行时/部署逻辑）；不参与在线增量更新（升级=替换文件）；SmartScreen 与安装版同为未签名提示（放行步骤见 README）

## 更新说明

- 老用户安装 v0.2.1：启动时版本指纹不一致 → 自动重部署运行环境（约 30 秒，可跳过；**用户自装插件/自定义 MCP 预置将保留**——本版护栏）
- 全新安装：首启自动部署（进度条），全程无需 Node.js / pnpm
