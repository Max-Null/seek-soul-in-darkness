## 五、关键结论

1. **约 70% 资产 DSH 原生覆盖**（✅）：会话/消息/工具/权限/配置/时间线/国际化/技能/MCP/压缩——这些在 DSH 是开箱即用的，fractal 三代攒的"通用能力"大部分不用重做。
2. **真正的增量工作收敛为 5 块**（🔌/🎨）：
   - 自研 SSiD 壳（参考 anywhere-labs，不换皮）
   - dsh-memory 补 UI 面板 + Guardian 触发线/状态面板（M1+M2）
   - 四 agent 编排（M3）
   - 14 技能包（skill 化）
   - 诊断面板、PDF 转换等零散自研面板
3. **待核实项 6 处**（⚠️）：上下文指示/上下文面板、文件修改卡片、历史子任务、繁忙时 Enter——需实测 DSH Web GUI 确认对应组件。
4. **已死资产不迁**（❌）：CC 专属的 Zen 模式等，fractal 阶段就移除了，SSiD 无需再考虑。
