> 目标：让 SSiD 从「浏览器」变「独立 exe」，并确认 dsh-memory / dsh-chinese-thinking 在壳内生效

## 一、anywhere-labs 的架构（关键结论）

`anywhere-labs/deepseek-harness-desktop` 的机制（已读源码核实）：

```
Electron（仅 bootstrap）
  ├─ 单实例锁 + profile 解析 + 原生托盘
  ├─ 在 Electron main 进程内 boot 官方 DSH Host Cordis root
  ├─ Host 绑定 HTTP/WebSocket 到 127.0.0.1（ephemeral 端口）
  └─ sandboxed renderer 加载同一 origin 的「官方 Web UI 本体」
```

**核心发现：插件的接入是完全标准的 DSH 机制，零桌面改造**（源码原文）：

> A third-party Host plugin only needs its normal `dsh.bundle` patch. A plugin with browser UI also publishes the normal `dsh.client` metadata with `platform: "web"` and an exported `./client` artifact. The upstream Web client module graph discovers it in both modes; Electron does not require a separate client build or a desktop-specific registration API.

含义：**dsh-memory、dsh-chinese-thinking 直接 `dsh plugin add` 就能进壳，无需任何 Desktop 专属代码。**

两个 Desktop 专属服务（仅当插件需要桌面能力时才用）：
- `desktopProfiles`：读/切换 profile
- `desktopPnpm`：`dsh plugin --profile <active>` 语义的插件安装/更新/移除

## 二、最小闭环两条路径

### 路径 A：直接下载安装包（最快，验证用）

1. 打开 https://www.deepseekdesktop.com 下载 Windows 安装包（已发布 macOS/Windows）。
2. 安装后启动，默认 `desktop` profile，窗口内即官方 DSH Web UI。
3. 验证插件：

```powershell
# 打开 DSH Terminal（托盘菜单），或命令行：
dsh plugin --profile desktop add @max-null/dsh-memory
dsh plugin --profile desktop add @max-null/dsh-chinese-thinking
```

4. 重启应用，确认：①中文思考生效；②`memory_save/list/search/confirm/forget` 工具可用。

> 路径 A 不涉及任何构建，是「选壳验证」的最短路径。

### 路径 B：自构建（二次开发 / 换 logo 用）

环境要求：Windows x64 + Git + Node `^22.19 || >=24`（corepack 自带）+ yarn 4。

```powershell
git clone --recursive https://github.com/anywhere-labs/deepseek-harness-desktop
cd deepseek-harness-desktop
git submodule update --init --recursive   # deepseek-harness 上游 submodule
corepack.cmd yarn install --immutable
corepack.cmd yarn dev                      # 构建并启动（开发）
# 打包 Windows 安装包（产出 dsh-plugin-desktop\dist\DSH-Desktop-2.0.0-x64-Setup.exe）：
corepack.cmd yarn dist:win
```

## 三、SSiD 换壳（logo / 品牌替换点）

若要在 anywhere-labs 之上做 SSiD 品牌（路径 B 才有意义）：

| 替换点 | 文件 | 说明 |
|---|---|---|
| 应用图标 | `build/app-icon.png`（+ `scripts/generate-mac-app-icon.mjs`） | 换成 Si 原子 + 瞳孔 logo |
| 托盘图标 | `build/tray-icon.svg` | 同 logo，品牌蓝 |
| 窗口标题 | `dsh-plugin-desktop` 内 `desktop-shell` 的 caption | 显示名「思灵」 |
| 模式命名 | `dsh-desktop.mode`：compatibility / advanced | 可保留，或映射到品牌主题名 |

> 建议：先用路径 A 验证「DSH GUI + 壳 + 你的插件」闭环成立；品牌替换留到确定长期用 anywhere-labs 后，再 fork 走路径 B。

## 四、风险与注意

1. **Linux 不支持高级模式**（仅 compatibility）；SSiD 目标 Windows 优先，暂不受影响。
2. **自构建较重**：submodule（官方 DSH 上游）+ yarn 4 + Electron 二进制下载，建议只在「确定要改壳」时走路径 B。
3. **插件安装需重启**：增删 profile bundle 后必须重启应用（launcher 不 watch manifest）。
4. **dshmarket@1.2.3 有坑**（源码 README 明确）：缺完整 MIT license 文本、未消费 desktopPnpm，不预装。SSiD 用官方 `dsh plugin` 即可，别用 dshmarket。
